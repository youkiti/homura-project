# システマティックレビュー（SR）のデータを買い取ります

HOMURA プロジェクトでは、SR 支援ツールの性能を評価するデータセットを作るため、過去に実施されたSRの記録（プロトコル・検索式・スクリーニングの判定・データ抽出とリスク・オブ・バイアスの判定）を買い取ります。

## 対象になるSR

次のすべてに当てはまるSRが対象です。

1. 出版済みのSRであること（DOI か PMID があるもの。診療ガイドラインの一部として公表されたものを含む）
2. 本プロジェクトの開始日（2026年9月7日）より前に完了していること
3. 下の「必要なファイル」の5点がすべてそろっていること。リスク・オブ・バイアスの評価やデータ抽出を行っていないレビュー（スコーピングレビューなど）は対象外です
4. 登録プロトコル（PROSPERO 等）か出版済みのプロトコルがあること
5. あなたの所属先（SRを作成した時点の所属先を含む）が、このデータについて権利や管理権を持たないこと
6. 共著者と、一緒に判定した方（スクリーニング・データ抽出・リスク・オブ・バイアスの判定を行った方）の了承を得ていること

同じSRは1回だけ購入します。複数の共著者が同じSRを申し込んだ場合は、先に申し込んだ方の1件だけを受け付けます。共著者の間で、どなたが申し込むかを決めてからお申し込みください。

## 必要なファイル（SR 1本につき5点）

| # | ファイル | 内容 |
| --- | --- | --- |
| 1 | プロトコル | 登録プロトコル又は出版済みプロトコル |
| 2 | 検索式 | 検索したすべてのデータベースの検索式。検索日と各データベースのヒット件数を付ける。更新検索があれば全回分 |
| 3 | タイトル・抄録スクリーニングの判定 | 記録ごとの個人の判断と、不一致解消後の判断（個人の判断が残っていなければ解消後のみで可） |
| 4 | フルテキストスクリーニングの判定 | 同上。最終判断がツールに残っていなければ、出版論文の研究一覧で代えられます |
| 5 | データ抽出とリスク・オブ・バイアスの判定 | 同上 |

- 形式は CSV か Excel（.xlsx）です
- 判定ファイルの件数の合計は、PRISMA フロー図の該当段階の件数と合わせてください
- 判定ファイルに残してよい書誌は、記録ID・タイトル・著者・出版年・誌名・巻・号・ページ・PMID・DOI だけです。抄録と統制語（MeSH・Emtree など）は消してください
- 判定者の氏名は、提出前に A・B などの記号に置き換えてください（同じ人には同じ記号。対応表は不要です）

次のものは受け取りません：検索結果の書誌ファイル（RIS 等）、抄録、論文の PDF。

## 流れ

1. 申込フォームで、本人の情報・お振込先・提供するSR・契約書への同意を送信する（ファイルはまだ送らないでください）
2. 研究班が内容を確かめ、発注書を電子メールでお送りします。この時点で契約が成立します
3. 発注書の送付から4週間以内に、案内するファイル提出フォーム（又は共有フォルダ）へ、SRごとにファイルを提出する
4. 研究班が提出から10日以内に検収します。不足や消し忘れがあれば、修正をお願いします
5. 研究班が作成する納品書・請求書に記名して返送いただき、請求書の受理から60日以内に名古屋大学からお振り込みします

## データの使い方と公開

- 判定・抽出・リスク・オブ・バイアスのデータとプロトコルは、CC BY 4.0 で公開する予定です
- 公開する書誌（PMID・DOI・タイトル・誌名・巻号・ページ）は、研究班が無料で公開されている情報源から取り直したもので作ります。抄録は公開しません
- データは、生成AI（海外の事業者が提供するサービスを含む）に入力して処理し、モデルの学習や改良に使うことがあります
- 公開したデータを第三者が取得し、生成AIで処理することを、提供者に了承いただきます
- 謝辞にお名前を載せるのは、申込フォームで同意いただいた場合だけです

詳しくは契約書の第6条から第8条をお読みください。
